About the Research Assistant

How a small, locally run tool helps make complex legislation searchable — and where, if anywhere, larger AI models enter the picture.

To help people understand and compare policy for the betterment of all, the Research Assistant is built on a vector database. We compile the full text of housing-related policies and bills into this database so that searching it helps us understand and evaluate complex legal documents — and surfaces related measures that may bear on whatever is under review.

A language model is involved, but it is a small, locally run application that uses very little power — you could run it on a laptop. This architecture is called retrieval-augmented generation (RAG), and it is among the most efficient ways to put a language model to work.
